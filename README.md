# 🤖 Portfolio Chatbot - Issam Chatbouri

Portfolio interactif sous forme de chatbot IA pour Issam Chatbouri, étudiant ingénieur en génie informatique.

Les recruteurs et visiteurs peuvent poser des questions sur le parcours, les projets et les compétences d'Issam, et le chatbot répond à sa place de manière naturelle et professionnelle.

## ✨ Fonctionnalités

- 💬 **Assistant RH bilingue** : réponses contextualisées via Groq et réponses de secours basées sur le portfolio
- 🎯 **Réponses en streaming** avec effet de frappe en temps réel
- 🎨 **Design moderne** responsive (mobile-first) avec mode sombre/clair
- 🔒 **Réponses ancrées** dans les informations du portfolio, avec validation des requêtes
- 🌐 **Multilingue** : détection automatique FR/EN
- 📱 **Suggestions de questions** cliquables pour guider les visiteurs
- ⚡ **Performance optimale** : Next.js 14 + TypeScript
- 🎭 **SEO optimisé** avec Open Graph pour les partages LinkedIn/WhatsApp
- 🆓 **Réponses aux questions courantes sans clé** ; `GROQ_API_KEY` active les réponses conversationnelles aux questions ouvertes
